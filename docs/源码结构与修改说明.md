## 这次具体修复了什么

1. 原 `libarchive-wasm` 加载器误用 Node/浏览器全局；而真实中文 7z 还存在文件名被替换为星号的缺陷。现在 7z/RAR 改用 7-Zip C++/WASM 的 Unicode 读取器，旧加载器回归检查保留。
2. 原“审核并下载全部”会在一个请求内反复解压、审核和导出，超出云端资源后任务可能停在处理中。现在每次只占用一个学校的审核任务，结果存库后再单独下载。
3. 自动审核开始/结束通过普通数据库条件更新避免多个页面抢跑；完成写入核对任务仍存在且未被新版本替代，避免删除后被旧审核复活。
4. 起始日期自动保存固定使用北京时间；连续修改串行写入最新值，收集前等待未完成的保存，避免用旧日期扫描。
5. VS Code 工作区、F5 调试、首次配置、原生 C++ 构建与测试说明随源码提供。

## 保留的安全边界

- 共享密码、会话、请求来源验证和敏感配置不移除。
- 保留压缩包文件数、目录深度、单文件/总解压量限制，拒绝加密包、路径穿越、链接和特殊文件。
- 单校或批量删除保留二次确认；若被删任务不是当前最新提交，保留新版本并返回独立失败信息。
- 所有证据不足的审核意见保留“待人工确认”，不把运行时异常说成参赛队文件不合格。
- 源码压缩包不含密码、会话、数据库、参赛学校原始文件或依赖缓存。

## 第三方组件与许可

7-Zip WASM 为 `7z-wasm@1.2.0`（7-Zip 24.09），LGPL + unRAR 限制；它是独立可替换的第三方库，并非项目自有代码。
源码/构建说明：https://github.com/use-strict/7z-wasm 。完整许可随 npm 包的 `License.txt` 安装。不得利用其中 unRAR 部分开发兼容 RAR 的压缩器。
本项目保留库的独立加载与版本锁定，没有将其重新许可。
其余第三方库遵循各自许可；依赖版本记录在 `package-lock.json`，使用 `npm ci` 复现。

核心新增逻辑已有边界和原因注释；避免把每行直译成注释，以便后续开发者理解真正的业务约束。
