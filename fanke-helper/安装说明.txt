Chem-E-Car 赛事资料采集助手 1.5.0（Edge / Chrome）

用途
----
- 凡科：只收集报名表和 EDP。
- 阿里邮箱：只收集海报和视频附件，并协助把报名表、EDP 回执写入草稿箱。
- 助手复用浏览器里已经登录的页面，不保存凡科或阿里邮箱账号、密码，也不需要开通凡科“数据推送”。

首次安装或更新（只做一次）
------------------------
1. 将下载的 chemecar-fanke-helper.zip 解压到一个固定文件夹，不要直接在压缩包内打开。
2. Edge：在地址栏输入 edge://extensions
   Chrome：在地址栏输入 chrome://extensions
3. 打开“开发人员模式”。
4. 若已安装旧版，请先删除或停用旧版；再点击“加载解压缩的扩展”，选择包含 manifest.json 的文件夹。
5. 刷新赛事资料中心一次；页面应显示“助手已连接 v1.5.0”。

登录要求
--------
1. 凡科采集前，只需在同一浏览器登录凡科；不必手动进入表单结果页，也不必回到第一页。
2. 海报、视频收取或回执写入前，只需在同一浏览器登录阿里邮箱；不必手动刷新、打开收件箱或停留在写信页。
3. 浏览器关闭、退出登录或电脑休眠时，浏览器采集会暂停；重新打开浏览器并登录后继续。

报名表和 EDP（凡科）
-------------------
1. 在对应栏目保存独立的“收集起始日期”。
2. 点击“一键增量收集报名表”或“一键增量收集 EDP”。
3. 助手自动复用或打开凡科工作页、进入目标表单结果第一页并翻页，只核对该日期及之后的记录。
4. 每次只下载当前栏目真正需要的新文件、内容变化文件，或已从共享资料库删除而需要恢复的文件；其他类型附件直接跳过。
5. EDP 支持 ZIP、7z、RAR；压缩包可以先包含一个学校目录，再在目录内放置 PDF，不要求 PDF 必须位于压缩包根目录。
6. 第 1 次 EDP 需要中文版、英文版和增补文件 3 个 PDF；第 2–5 次再加 MOC，共 4 个 PDF。系统根据文件名和 PDF 首页共同识别角色，不要求每个文件名都含“EDP”。
7. 压缩包可额外包含一份同校 XLSX 随包报名表：它不计入 EDP 文件数；若提交时间更新且报名表有效，会更新报名表栏目和唯一统计表。随包报名表无效时只显示联动警告，不会推翻已合格的 EDP。
8. 加密压缩包、损坏压缩包、路径穿越文件或超出安全上限的压缩包会被拒绝，并在不合格清单显示原因。

海报和视频（阿里邮箱）
-------------------
1. 海报栏目和视频栏目分别保存起始日期、执行时间、频率，并可选择启用自动扫描。
2. 点击“立即扫描”可以马上扫描当前栏目；启用自动扫描后，赛事资料中心页面在浏览器中打开且阿里邮箱已登录时按所设频率运行。
3. 海报支持 AI、JPG、JPEG、ZIP、7z、RAR；视频支持 MP4、ZIP、7z、RAR；单个文件最大 200MB。
4. ZIP、7z、RAR 只有在文件名、邮件主题或附件附近文字能够明确判断是海报或视频时才自动归类；无法可靠判断的附件进入待核对清单，不会误存。
5. 助手只读取附件，不会发送、删除、移动、标记或修改原邮件。

共享文件与增量规则
----------------
- 文件收集后保存在赛事资料中心的共享云端，不会自动进入当前电脑。
- 在对应栏目下方清单点击“保存到本地”可下载；点击“删除”并二次确认可从所有用户共享的资料库移除；支持多选批量删除。
- 同一学校只保留提交时间最新且符合规则的一版。
- 云端文件存在且内容未变化时直接跳过；若云端文件已被删除，下次增量扫描会重新下载并恢复。
- 起始日期之前的记录不下载；各栏目互不共用起始日期和增量状态。

报名表和 EDP 回执写入阿里邮箱草稿
--------------------------------
1. 先在赛事资料中心保存竞赛年份、QQ 群号或 EDP 提交轮次等回执设置。
2. 可对单所学校写入，也可勾选后按学校逐封写入。
3. 助手分别填写收件人、邮件主题和正文，逐项回读成功后才保存为草稿；缺少有效收件人时跳过该校并继续处理后面的学校。
4. 助手绝不会自动发送邮件。写入完成后请在阿里邮箱草稿箱逐封检查，确认无误后由操作者发送。

EDP 审核与 Excel
----------------
1. EDP 提交统计只负责压缩包数量、PDF 格式和回执；独立的“EDP 审核”栏目才生成逐项审核意见。
2. 审核只处理每校最新且提交成功的 EDP。自动判定只能依据可定位的明确证据，状态只有“是、否、不适用、待人工确认”。
3. 证据不足、矛盾、图片模糊或无法可靠解析时保留“待人工确认”，由审核人员查看文件名、页码和摘录后处理。
4. 草稿 Excel 可保留待确认项；正式 Excel 必须在所有待确认项处理完并完成最终确认后生成。
5. 每校生成一份含两个工作表的 Excel，可在 EDP 审核栏目下载或删除；删除审核 Excel 不会删除原始 EDP。
6. 如果已有合格 EDP 但审核清单缺失，点击“同步并刷新审核任务”。系统只补建缺失任务，不重复创建，也不重置已经开始或完成的审核；单个学校失败不会阻断其他学校。
7. 审核意见表只需选择竞赛年份；安全与规则审查人、邮箱和专家组成员由系统固定填写。

注意
----
- 目前只支持电脑端 Edge 或 Chrome；手机浏览器不能安装此助手。
- 凡科或阿里邮箱页面结构若发生调整，助手会明确提示“未识别”，不会把未知内容静默归错。
- 助手仅访问凡科页面、阿里邮箱页面和赛事资料中心；自动打开的页面只复用已有登录状态，不读取账号密码。
